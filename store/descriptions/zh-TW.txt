先看懂標題背後的內容，再決定要不要花時間閱讀。debait 使用 AI 建議不聳動的標題、整理擷取到的文章內容，並評估標題的騙點閱手法。

使用前先設定
請自備 AI 供應商的 API 金鑰，或設定本機模型。使用雲端供應商可能產生費用。開啟「設定」，選擇供應商、視需要貼上金鑰，然後儲存。

儲存前可按「測試連線」，檢查目前填寫的供應商、模型、API 基底網址與金鑰。測試會發出一次小型生成請求，可能使用配額或產生費用，但不傳送文章內容或自訂指示。成功代表模型有回傳文字；配額錯誤不一定表示金鑰無效。

你會得到什麼
• 誠實標題建議：不靠誇大與懸念，說明文章在講什麼。
• 簡短摘要與重點。
• 0–100 的騙點閱分數，以及偵測到的手法說明。
• 內容評估：有料、單薄或空洞，並建議完整文章是否還有值得閱讀的資訊。

兩種用法
分析目前文章：點工具列圖示，選擇「分析這個頁面」；或在頁面上按右鍵，選擇「debait 這個頁面」。
點擊前預覽連結：在設定中選擇 Shift + 懸停、Alt + 懸停，或不按修飾鍵懸停，然後儲存。Shift 預覽需要移動滑鼠，只按 Shift 不會啟動。全新安裝預設使用 Shift；既有選擇依設定移轉規則保留。不按修飾鍵模式可能不經額外點擊，就抓取連結頁面並傳送內容到你的 AI 端點，使用配額或產生費用。也可以在 HTTP／HTTPS 連結上按右鍵，選擇「debait 這個連結」，不用開啟目標頁面，就能在可關閉的面板閱讀預覽。

載入中、錯誤與結果面板都可以關閉，較晚收到的回應不會重新開啟。面板顯示來源網域；連結預覽提供「開啟所要求的文章」，只在你點擊時開啟原要求網址。Escape 可關閉符合條件的面板，不干擾頁面欄位與對話框。

語言與偏好
你可以在設定中選擇摘要的輸出語言，並加入自訂指示。尚未儲存的欄位顯示「已修改」；儲存會保存變更，捨棄變更會恢復此頁面上次儲存的設定，包括其他供應商的設定。捨棄或連線測試成功都不會自動儲存新的設定。介面可選英文、繁體中文，以及尚待母語者校對的台語漢羅翻譯草稿。介面語言與摘要語言是分開的設定。

使用量控制
懸停預覽提供可調整的延遲、最小呼叫間隔與每日上限；遇到供應商配額錯誤時，也會暫停呼叫。右鍵連結預覽共用相同的快取、呼叫間隔、每日上限與暫停機制。這些控制可減少請求，但不能保證不超過供應商配額。取消不能收回已發出的網站或 AI 請求；已保留的預覽次數即使稍後取消，也可能計一次。手動分析目前頁面與連線測試不受上述預覽使用量控制限制。

使用限制
分析使用擷取文字的前 12,000 個字元，不一定涵蓋完整文章。抓取預覽時不會執行目標頁面的 JavaScript，因此可能無法取得動態載入或付費牆後的內容。若擷取文字太少，預覽會顯示目標頁面的 meta description 或標題，而不是 AI 評估；若請求失敗，則會顯示錯誤。回應時間取決於供應商。

分數與摘要是 AI 產生的評估，不是事實查核、醫療建議或正確性的保證。重要資訊請查閱原始來源。

隱私
你選擇分析的頁面網址、標題、meta description、擷取文字及自訂指示，會傳送到你設定的 AI 端點。API 金鑰用於向該端點驗證身分。沒有開發者營運的伺服器處理你的分析。

金鑰與偏好設定使用 chrome.storage.sync；啟用瀏覽器同步時，可能透過該瀏覽器的同步服務同步。預覽嘗試次數與不含個資的全新／既有安裝分類標記儲存在你的裝置上。標記用於穩定懸停預設，明確儲存的模式優先。開發者不會收到你的分析請求。

自訂端點
自訂／OpenAI 相容端點需 API 基底網址與模型，金鑰可留空。文章與提示詞送至您信任的端點業者。無金鑰遠端 HTTP 未加密，可遭監看或竄改。有金鑰須用 HTTPS，回環位址除外。僅支援 Chat Completions，無模型探索或自動重試。
