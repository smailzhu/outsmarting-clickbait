在你點擊前，先看穿騙點閱。debait 會用 AI 讀完整篇文章，給你一個**誠實的標題**、簡短摘要、重點，以及 **0–100 的騙點閱分數**，讓你判斷這個連結值不值得點。

## 這是什麼

開啟任何文章後，點一下就能得到：

- **誠實標題** — 文章實際在講什麼，沒有誇大、沒有懸念釣魚。
- **摘要 + 重點**。
- **騙點閱分數（0–100）** 與偵測到的操弄手法。
- **是否值得點** — 有料／單薄／空洞。

兩種用法：

- 在文章頁面點工具列按鈕（或按右鍵 →「debait 這個頁面」）。
- 按住 **所選懸停鍵** 並把滑鼠移到任何連結上，在**點擊之前**就先預覽該連結的誠實標題與分數。

## 安裝（Chrome / Edge / Brave）

**Chrome 使用者建議直接從商店安裝：**開啟
[Chrome 線上應用程式商店](https://chromewebstore.google.com/detail/pcjbpicieggjfjldoekdeglnjhcdhjla?hl=zh-TW)，
按**加到 Chrome**。不需要開發人員模式，也不用下載 ZIP。
安裝後可從拼圖（擴充功能）選單釘選 debait，再開啟**設定（API 金鑰）**，
選擇供應商並填入自己的金鑰，或設定本機模型。

### 手動安裝（替代方式／開發版本）

## 設定（需自備 API 金鑰）

debait 使用**你自己的 AI 供應商與 API 金鑰**，費用與模型由你完全掌控。

1. 點工具列的 🪝🚫 圖示 →**設定（API 金鑰）**。
2. 選一個**供應商**（OpenAI、Anthropic（Claude）、Google Gemini、Groq、OpenRouter、DeepSeek、xAI（Grok）、Mistral、Together、NVIDIA，或本機 Ollama）。
3. 貼上該供應商的 **API 金鑰**，可先按**測試連線**，再按**儲存**。

「測試連線」使用目前填寫的供應商、模型與金鑰，不需要先儲存。
它會發出一次小型生成請求，可能使用配額或產生費用，但不傳送文章內容，
也不計入懸停預覽的每日上限。成功代表模型有回傳文字；若顯示 429，
請檢查供應商餘額與請求限制，不一定是金鑰無效。

> 想免費試用？Google **Gemini** 與 **Groq** 都有免費額度；或在本機跑 **Ollama**（免金鑰）。

## 使用方式

- **分析目前頁面**：點工具列圖示 →**分析這個頁面**，或在頁面上按右鍵 →「debait 這個頁面」。
- **點擊前預覽**：按住 **所選懸停鍵** 並把滑鼠移到連結上，稍候即可看到該連結的誠實標題與分數。
- **右鍵分析連結**：在 HTTP／HTTPS 連結上按右鍵 →「**debait 這個連結**」，不用開啟目標頁面，就能在可關閉的面板閱讀結果。此功能共用懸停預覽的快取、限流與每日上限。
- **輸出語言**：摘要可用任何語言輸出（在設定中填寫；留空＝與文章一致）。

## 懸停同意與取消（原始碼／開發版本）

這是**擴充功能限定**的原始碼功能，不代表商店已推出。設定可選 Shift + 懸停、Alt + 懸停或不按修飾鍵懸停；按**儲存**後才套用，未儲存／失敗不影響內容頁，捨棄還原基準。新本機狀態沒有已存設定時預設 Shift；首次初始化已看見的舊設定保留 Alt，舊布林 false 保留「不按修飾鍵懸停」。按住 Shift 並移到連結；只按 Shift 絕不預覽，即使 0 毫秒也一樣。Alt 可在非編輯、無已觀察快捷鍵／組字時重新按下啟動靜止預覽。Shift+點擊可能開新視窗，放 Alt 可能顯示選單；不要點擊來啟動。Userscript 仍是獨立 Alt 懸停，右鍵手動分析不受影響。

本機 AI 設定缺少或無效時，會在目標擷取、供應商呼叫與預覽配額作業之前顯示純文字設定指引；此暫時結果不快取。選「不按修飾鍵懸停」時，每個符合移動與停留條件的連結懸停都可能顯示設定提示，直到完成設定。此結果不掃描、不預載、不自動開啟設定，也不聯絡連結網站。免金鑰供應商可通過本機檢查，但無法連線時懸停仍顯示一般錯誤；儲存設定不會驗證金鑰。右鍵手動連結分析共用可關閉的設定提示。原生修飾鍵與三語提示版面驗證仍待完成。

本機來源標記不是跨裝置歷史：先用原始已存欄位分類，之後自動設定檔遷移／晚到的純設定同步不會把新 Shift 變 Alt。已發布 0.3.0 沒有懸停偏好欄位，若純設定晚到仍是 Shift；請明確選 Alt 並儲存。新裝置／重裝／清本機以當時可見資料重判。明確 canonical 偏好優先；錯誤值安全用 Shift，舊 false 用「不按修飾鍵懸停」，其他舊值用 Alt。儲存同時寫 canonical 與舊鏡像，舊版將 Shift 當 Alt。清同步保留本機標記；清本機缺少 fallback 時停用自動懸停，須待操作結束重新載入設定或工作程序。鎖／儲存初始化失敗會鎖住設定、儲存、捨棄、測試連線；手動分析仍以記憶體遷移運作，不持久寫入設定檔。外部清除非跨區原子操作，不會自動修復。詳見[原始碼契約與原生測試清單](docs/hover-activation.md)。

選不按修飾鍵懸停後，符合移動條件的一般懸停可能聯絡連結網站，並將網址、標題、描述與擷取文字送至你的 AI 端點，使用配額且可能產生費用。建議保留適當停留時間（預設 500 毫秒）；較短時間，包含 **0 毫秒**，可能在指標一停在連結上就開始預覽。0 仍使用非同步計時器，沒有隱藏的最低值。連結網站的擷取在既有 AI 限流檢查之前；間隔與上限可設為 0（無限制），無法防止所有網站聯絡。

懸停需網頁**可見且取得焦點**及瀏覽器信任的輸入。初次啟動或恢復焦點後，第一個位置事件只建立螢幕位置基準，可能需要再實際移動滑鼠。Alt 模式在非編輯、無已觀察快捷鍵／組字的有效靜止連結重新按下 Alt（非重複按鍵）也可啟動一次停留。連結內子元素間移動不重啟；放開 Alt 只取消要求 Alt 模式的懸停，不影響關閉要求的模式。捲動、點擊／右鍵、DOM 取消或已儲存的懸停偏好變更後，自動懸停需再次移動指標，或在要求模式重新按 Alt。生命週期與設定變更不會自動重試。螢幕座標相同，即使網頁座標或指標下連結改變，也不能啟動新的自動停留。關閉要求的模式仍信任螢幕座標改變後的瀏覽器邊界事件；這**不是硬體動作驗證**，受信任事件本身不證明使用者意圖。

移開滑鼠、變更／移除連結、捲動、按下指標／右鍵、失焦、隱藏與 pagehide 只撤回該懸停連接埠的需求。AI 送出前最後一個擁有者離開，工作程序會中止目標準備；同網址的其他懸停或手動擁有者仍可保留共用工作。每個非同步準備後及呼叫 AI 前都檢查需求。這是**工作程序已觀察到的取消**：IPC 尚在傳送中的斷線可能趕不上送出。無法撤銷已聯絡的網站、已送出的 AI 請求或費用。耐久配額預留寫入期間取消，即使沒有 AI 呼叫，仍可能消耗一單位與間隔時段；不承諾回復或退款。送出後工作繼續；成功且未過期的結果即使沒有懸停擁有者，也可快取 30 分鐘，同設定後續命中無需新網站擷取、AI 請求或配額。錯誤、過期及送出前取消的工作不快取；成功的薄內容中繼資料仍免費且可快取。

不掃描連結或預載。單一有效懸停在停留、準備與顯示結果期間觀察子樹移除與 href 變更，只檢查擷取的連結與相關紀錄；文件範圍的變動觀察仍可能在繁忙網頁耗用 CPU。原生 Chromium 連接埠壽命、工作程序暫停／重載、bfcache、版面事件、無障礙與作業系統 Shift／Alt 行為需瀏覽器驗證，Node 測試不代表已驗證。

## 省錢與配額

**懸停預覽**會自動限流、遇到供應商限流（HTTP 429）時自動退避，並遵守你設定的**每日上限**，降低不小心耗盡配額的風險（退避時間不可調整）。

請注意：手動的「**分析這個頁面**」（工具列按鈕或右鍵）每次都會呼叫一次 AI，**不受**上述每日上限與限流限制。懸停延遲、間隔與每日上限都可在**設定**中調整。

## 隱私

沒有 debait 伺服器。頁面文字只會傳送到**你設定的供應商**；API 金鑰與設定儲存在你的瀏覽器（透過 `chrome.storage.sync`，可能會透過你的 Google 帳號同步到你登入的其他瀏覽器），不會傳給開發者。完整政策見 [PRIVACY.md](PRIVACY.md)。
