## 懸停同意 kah 取消（原始碼／開發版本；台語草稿）

這是**擴充功能限定**的原始碼功能，不代表商店已推出。設定可選 Shift + 停佇頂懸、Alt + 停佇頂懸或免按修飾鍵、停佇頂懸；按**儲存**後才套用，未儲存／失敗不影響內容頁，捨棄還原基準。新本機狀態沒有已存設定時預設 Shift；首次初始化已看見的舊設定保留 Alt，舊布林 false 保留「免按修飾鍵、停佇頂懸」。按住 Shift 並移到連結；只按 Shift 絕不預覽，即使 0 毫秒也一樣。Alt 可在非編輯、無已觀察快捷鍵／組字時重新按下啟動靜止預覽。Shift+點擊可能開新視窗，放 Alt 可能顯示選單；不要點擊來啟動。Userscript 仍是獨立 Alt 懸停，右鍵手動分析不受影響。

本機 AI 設定欠缺抑是無效，佇目標擷取、供應商呼叫 kah 預覽配額作業進前會顯示純文字設定指引；這个暫時結果無快取。揀「免按修飾鍵、停佇頂懸」時，每个符合移動 kah 停留條件 ê 連結懸停攏可能顯示設定提示，直到設定好。這个結果無掃描、無預載、無自動拍開設定，嘛無聯絡連結網站。免金鑰供應商會使通過本機檢查，毋過連袂著時懸停猶顯示一般錯誤；儲存設定無驗證金鑰。右鍵手動看連結共用會關 ê 設定提示。原生修飾鍵 kah 三語提示版面驗證猶待完成。

本機來源標記不是跨裝置歷史：先用原始已存欄位分類，之後自動設定檔遷移／晚到的純設定同步不會把新 Shift 變 Alt。已發布 0.3.0 沒有懸停偏好欄位，若純設定晚到仍是 Shift；請明確選 Alt 並儲存。新裝置／重裝／清本機以當時可見資料重判。明確 canonical 偏好優先；錯誤值安全用 Shift，舊 false 用「免按修飾鍵、停佇頂懸」，其他舊值用 Alt。儲存同時寫 canonical 與舊鏡像，舊版將 Shift 當 Alt。清同步保留本機標記；清本機缺少 fallback 時停用自動懸停，須待操作結束重新載入設定或工作程序。鎖／儲存初始化失敗會鎖住設定、儲存、捨棄、測試連線；手動分析仍以記憶體遷移運作，不持久寫入設定檔。外部清除非跨區原子操作，不會自動修復。詳見[原始碼契約與原生測試清單](docs/hover-activation.md)。
